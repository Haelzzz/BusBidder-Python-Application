# BusBidder Spain

A Python application that filters and ranks fictional bus offers from Madrid
using a transparent weighted scoring model. Final project for ACIT4420
(Problem-solving with scripting), OsloMet.

## Requirements

- Python 3.11 or newer (developed with 3.13)
- No third-party runtime libraries (standard library only)
- `pytest` for the tests (see `requirements.txt`)

## Setup

From the project root:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -e ".[dev]"
```

`pip install -e .` makes the `busbidder` package importable from anywhere.
It is optional: the commands below also work without it (see *Running*).

## Running

```bash
python -m busbidder
```

This opens a menu: search (destination, dates, seats, budget, traveller
profile), see the filtered and ranked offers with an explanation, and book one.
Payment is simulated. To print the profile comparison on the example trip
without any questions (e.g. to save the output):

```bash
python -m busbidder --compare
```

On start the program loads and validates `data/`. Rejected records are written
to `logs/rejected_records.csv`, bookings to `bookings/bookings.json`, and the
full log to `logs/busbidder.log`. Traveller profiles are in `config/profiles/`.

Without the editable install, either set `PYTHONPATH=src` first or run the
entry file directly: `python src/busbidder/__main__.py`. In VS Code, use the
**BusBidder** launch configuration (Run and Debug panel) or "Run Python File"
on `src/busbidder/__main__.py`.

## Data

The input files in `data/` are generated by a reproducible script (fixed
seed 4420) and committed, so the program runs without generating them first.
To regenerate them:

```bash
python scripts/generate_data.py
```

Options: `--seed N` for a different dataset, `--out DIR` to write elsewhere.

| File | Contents |
|---|---|
| `data/companies.json` | The five bus companies |
| `data/destinations.json` | The fifteen destinations served from Madrid |
| `data/offers.csv` | Bus offers 8-19 July 2026, including 12 deliberately invalid rows |
| `data/injected_errors.json` | Which rows are invalid and why |

## Project layout

| Path | Contents |
|---|---|
| `src/busbidder/` | Application package |
| `src/busbidder/models/` | Domain classes (Company, Destination, Offer, ...) |
| `src/busbidder/data_io/` | Loading and validating data files |
| `src/busbidder/filtering/`, `ranking/`, `booking/` | Later tasks |
| `data/` | Input data (companies, destinations, offers) |
| `config/` | `settings.json` and traveller profiles |
| `logs/` | Log file `busbidder.log` (created at run time) |
| `scripts/generate_data.py` | Reproducible dataset generator |
| `tests/` | pytest test suite |
